# Googleスプレッドシート 受注データ 整理・転記・集計ツール

表記がバラバラな受注データ（空白・全角半角・日付形式・金額の書き方・担当者名の揺れ・重複）を、メニューから「整理・転記を実行」を押すだけで自動で整え、整理済みデータシートへの転記・確認が必要なデータの振り分け・担当者別などの集計まで行うツールです（Google Sheets / Google Apps Script）。

[作品一覧](https://github.com/moedaichi0629-ai/landing-page) · [ポートフォリオ](https://moedaichi0629-ai.github.io/)

> **このリポジトリについて**
> 受託開発を想定して制作した**ポートフォリオ用の模擬案件（デモ）**です。実在のクライアント・実案件ではなく、「複数人が手入力している受注一覧を、毎回手作業で整えて集計している小規模事業者」を想定し、要件定義から実装・テストまでを一貫して行いました。リポジトリ内のサンプルデータ（会社名・担当者名・金額など）はすべて架空のものです。

## 作業前 → 作業後

| | 作業前（想定） | 作業後 |
|---|---|---|
| 表記の統一 | 余分な空白・全角半角・「山田 太郎」「ﾔﾏﾀﾞ」などの揺れを1件ずつ目で探して直す | 実行するだけで自動で統一 |
| 日付・金額 | 「2026年9月3日」「¥50,000」「２０，０００円」などを手で直さないと計算できない | 日付と数値に自動で変換 |
| 重複データ | 同じ受注が2回入力されていても気づきにくい | 整理後の内容が同じ行を自動で除外 |
| 入力漏れ・誤り | 集計後に数字が合わず、原因の行を探すことになる | 「要確認」シートに理由付きで振り分け（データは消さない） |
| 転記 | 別シートへコピー＆ペースト。何度も貼ると二重になる | 新しいデータだけを追記。何度実行しても二重転記しない |
| 集計 | 担当者別・ステータス別にフィルタや電卓で数える | 集計シートを自動で更新 |

※本ツールが解決しようとする課題設定上の想定であり、実際の削減効果を示す実績ではありません。

### 整理の例（同梱のサンプルデータより）

| 入力データ（整理前） | 整理済みデータ（整理後） |
|---|---|
| `2026-09-02`／`␣␣テスト工業株式会社␣`／`山田 太郎`／`¥50,000` | `2026/09/02`／`テスト工業株式会社`／`山田`／`50,000` |
| `2026年9月3日`／`ｻﾝﾌﾟﾙ企画`／`ｻﾄｳ`／`２０，０００円` | `2026/09/03`／`サンプル企画`／`佐藤`／`20,000` |
| `2026/9/4`／`ＨＰ制作`／`受付済`／`300,000` | `2026/09/04`／`Webサイト制作`／`受付`／`300,000` |
| `2026/09/06`／`サンプル食堂`／`三万円` | 「要確認」へ（理由：金額を数値に変換できません（入力値: 三万円）） |

（`␣` は余分な空白を表しています）

## 主な機能

- **ワンクリックで整理・転記・集計**：カスタムメニュー「データ整理」→「整理・転記を実行」だけで、整理から集計までまとめて実行
- **表記の自動統一**：前後の余分な空白を削除し、全角英数字・全角スペースを半角に、半角カタカナを全角に統一
- **日付形式の統一**：`2026/9/3`・`2026-09-03`・`2026.9.3`・`2026年9月3日`・`20260903` などを日付にそろえる。存在しない日付（`2026/13/01` など）は要確認へ
- **金額の数値化**：`¥`・`￥`・`円`・`,`（全角含む）を取り除いて計算できる数値に変換
- **表記ゆれ設定**：「山田太郎 → 山田」「HP制作 → Webサイト制作」「受付済 → 受付」のような対応表をシート上で編集でき、担当者名・商品名・ステータスを統一
- **重複除外**：整理後の内容が完全に一致する行は、2件目以降を除外（何行目と同じかを表示）
- **要確認シートへの振り分け**：入力不足・変換できない値がある行は削除せず、元の入力値と理由を「要確認」シートに表示
- **二重転記の防止**：転記済みのデータは何度実行しても追加されない。要確認だった行は、入力を直して再実行すればその行だけが転記される
- **処理結果の表示**：入力データのG列に「転記済み」「要確認」「重複除外」を記入し、完了メッセージで件数を表示
- **同時実行の防止**：メニューを続けて押しても処理が重ならない（LockService）

## 処理の流れ

```
入力データシート（受付日・顧客名・商品名・担当者・金額・ステータス）
   ↓
「整理・転記を実行」（カスタムメニュー「データ整理」）
   ↓
Google Apps Script
   ├─ 空白削除・全角半角の統一
   ├─ 日付形式の統一・金額の数値化
   ├─ 表記ゆれ設定に基づく担当者名・商品名・ステータスの統一
   ├─ 入力不足・不正な値のチェック
   └─ 重複データ・転記済みデータの判定
   ↓
振り分け
   ├─ 正常なデータ       → 整理済みデータシートへ追記（新しい分だけ）
   ├─ 確認が必要なデータ → 要確認シート（元の入力値＋理由）
   └─ 重複データ         → 転記しない（入力データの処理結果に「重複除外」）
   ↓
集計シートを更新（総受注件数・売上合計・担当者別・ステータス別）
   ↓
完了メッセージ（正常処理・要確認・重複除外の件数）
```

## 使用技術

- Google Sheets
- Google Apps Script（JavaScript）
- Node.js（ロジックの自動テスト用途のみ。本番機能では使用していません）

外部API・外部DB・外部サーバー・AIは使用していません。APIキー等の秘密情報も不要です（Googleアカウントの権限承認のみで動作します）。

## セットアップ

このリポジトリはclaspによる自動デプロイ構成ではありません。`gas/Code.gs`の内容を、Google Sheets上の「拡張機能」→「Apps Script」エディタへ貼り付けて利用します。

1. Google Sheetsで新規スプレッドシートを作成
2. 「拡張機能」→「Apps Script」を開く
3. `gas/Code.gs`の内容をエディタに貼り付けて保存
4. `setupDemoSheets`関数を1回実行する（初回は権限の承認画面が表示されます）
5. スプレッドシートを開き直すと、カスタムメニュー「データ整理」が表示されます

`setupDemoSheets`は次の5つのシートを作成します。既に同じ名前のシートがある場合、その内容は変更しません。

| シート | 内容 |
|---|---|
| 入力データ | 整理前のデータを入力するシート。初回は架空のサンプルデータ（13件）が入ります |
| 整理済みデータ | 整理後の正常なデータが追記されるシート |
| 要確認 | 確認が必要なデータと理由が表示されるシート |
| 集計 | 整理済みデータ全体の集計結果 |
| 表記ゆれ設定 | 担当者名・商品名・ステータスの統一ルール（初回はサンプルの設定が入ります） |

## 使い方

1. 「入力データ」シートにデータを入力（または他のファイルから貼り付け）する
2. メニュー「データ整理」→「整理・転記を実行」を押す
3. 完了メッセージで「正常処理」「要確認」「重複除外」の件数を確認する
4. 「要確認」シートに表示された理由を見て、「入力データ」シートの該当行（元の行番号）を修正し、もう一度実行する

- **毎日・毎週データを追加する場合**：入力データシートに追記して実行すると、新しいデータだけが整理済みデータへ追加されます。入力データシートの古い行を削除してから新しいデータを貼り付けても問題ありません。
- **表記ゆれを追加したい場合**：「表記ゆれ設定」シートに1行追加します（例：`担当者`｜`やまだ`｜`山田`）。対象項目は「商品名」「担当者」「ステータス」です。入力された表記は空白・全角半角・英字の大文字小文字を区別せずに照合します。

Node.jsが利用できる環境で、リポジトリのルートディレクトリで以下を実行します。

追加のパッケージインストールは不要です（`package.json`は用意していないため、`npm test`は使用できません）。テストでは `gas/Code.gs` を一切変更せずにNode上で読み込み、スプレッドシート・メッセージ表示・LockServiceを簡易な偽物に差し替えて、本番と同じコードを実行しています。

## 技術詳細・注意事項

<details>
<summary>要確認になる条件</summary>

次のいずれかに当てはまる行は「要確認」シートへ振り分けます。理由は1行に複数表示されることがあります。

| 条件 | 表示される理由の例 |
|---|---|
| 受付日・顧客名・商品名・担当者・金額・ステータスのいずれかが空欄 | 顧客名が未入力です |
| 受付日が日付として読み取れない、または存在しない日付 | 受付日が不正です（入力値: 2026/13/01） |
| 金額が数値に変換できない、マイナス、小数 | 金額を数値に変換できません（入力値: 三万円） |

要確認のデータは削除・修正せず、元の入力値のまま表示します。「要確認」シートは実行のたびに、その時点の入力データの内容で作り直されます。すべての項目が空の行は無視します。

</details>

<details>
<summary>重複除外と二重転記防止の仕組み</summary>

整理後の「受付日・顧客名・商品名・担当者・金額・ステータス」から**取込キー**を作り、整理済みデータシートのI列に保存しています。

- **同じ実行の中の重複**：取込キーが同じ行が複数ある場合、最初の行だけを転記し、2件目以降は「重複除外（○行目と同じ内容）」とします。表記が違っても、整理後の内容が完全に一致すれば重複と判定します。
- **前回までに転記済みのデータ**：取込キーが整理済みデータシートに既にある場合は追加せず、「転記済みのためスキップ」として件数だけを表示します。

そのため、同じ入力データで何度実行しても整理済みデータ・集計は変わりません。

注意点：

- 受付日・顧客名・商品名・担当者・金額・ステータスがすべて同じ受注は、別の受注であっても1件として扱います。同じ内容の受注が実際に複数ある場合は、整理済みデータシートへ手で追加してください。
- 転記後に入力データを修正すると、内容が変わるため新しいデータとして追加されます。転記済みのデータを直す場合は、整理済みデータシートを直接修正してください。
- 整理済みデータシートのI列（取込キー）は二重転記防止に使うため、削除・変更しないでください。

</details>

<details>
<summary>設計上のポイント・動作環境</summary>

- **整理処理をシートから切り離して実装**：1行分の整理・チェック、重複判定、集計は、スプレッドシートを操作しない関数にまとめています。そのため、Node.js上で本番と同じコードを自動テストできます。
- **全角半角の統一**：JavaScript標準のUnicode正規化（NFKC）を使用しています。Apps ScriptのV8ランタイム（現在の標準設定）で動作します。
- **日付の扱い**：日付はスクリプトのタイムゾーンで処理します。スプレッドシートとApps Scriptのタイムゾーンを「Asia/Tokyo」にそろえてください（ファイル → 設定／プロジェクトの設定）。
- **顧客名の名寄せはしない**：「株式会社サンプル商事」と「サンプル商事」のような別表記は、空白・全角半角以外は同じものとして扱いません。必要な場合は表記ゆれ設定の対象に追加する拡張が考えられます。

</details>
